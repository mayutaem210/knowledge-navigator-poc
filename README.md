# 欢迎使用

这是用于验证 Knowledge Navigator 概念的简单 POC。当前版本重点解决三个问题：

1. **知识在哪里？**
2. **遇到问题应该查看哪个流程或文档？**
3. **无法解决时应该联系谁？**

## 本POC的边界
<div class="notice">本网站使用示例内容，不应放入客户信息、价格、员工个人信息、账号、密码或其他内部敏感数据。正式对外发布前，需要由内容Owner和信息安全负责人确认可公开范围。</div>

## 建议验证指标
- 用户能否通过导航找到目标内容
- 搜索是否返回相关结果
- FAQ是否减少重复询问
- 找不到答案时是否能定位责任团队
- 内容Owner是否能够持续维护页面
