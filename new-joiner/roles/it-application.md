# IT Application 岗位学习地图

## 岗位目标
理解业务需求和端到端流程，支持应用稳定运行与问题分析，推动可维护、可审计的解决方案。

> POC示例，正式职责应由岗位Manager和应用Owner确认。

## 典型场景
- 接收业务问题或需求
- 判断业务、数据、权限、接口或系统方向
- 收集复现信息并分析
- 协同业务Owner、供应商和其他IT
- 管理测试、变更、发布和文档
- 将重复问题沉淀为知识

## 必须掌握
- 所支持业务流程的基础知识
- 应用与上下游系统关系
- 问题信息收集标准
- 测试、变更与发布要求
- 信息安全与访问控制原则

## 实践任务
1. 绘制一个端到端流程
2. 说明应用在流程中的作用和上下游
3. 使用标准模板记录问题
4. 识别业务判断与技术处理边界
5. 将已解决问题整理为FAQ
