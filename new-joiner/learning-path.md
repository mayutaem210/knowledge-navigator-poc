# 学习路径与检查清单

> 以下是POC模板，正式节奏由岗位Manager调整。

## 第1周：建立地图
- 了解公司与部门
- 明确岗位职责
- 认识主要协作角色
- 理解核心业务流程
- 完成系统入门

## 第2至4周：完成基础任务
- 跟随示例完成高频任务
- 学习岗位必须掌握知识
- 使用SOP、FAQ和检查清单
- 记录知识缺口

## 第2个月：形成独立处理能力
- 独立完成常规任务
- 理解上下游影响
- 完成常见异常基础排查
- 正确升级复杂问题
- 沉淀一条FAQ

## 第3个月：验证与改进
- 回顾岗位知识标准
- 通过实操或测验验证掌握程度
- 识别知识缺口
- 确认下一阶段目标

## 入职检查
- [ ] 已确认Manager和Buddy
- [ ] 已完成设备、账号和安全设置
- [ ] 已了解公司、部门和岗位职责
- [ ] 已理解至少一个核心流程
- [ ] 已获得必要系统权限
- [ ] 已完成一个基础任务
- [ ] 已找到相关SOP和FAQ
- [ ] 已知道异常升级路径
- [ ] 已提交一条知识反馈
